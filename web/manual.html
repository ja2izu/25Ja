25Ja（にこじゃ）説明書

UV-K1 / UV-K5(K6) V3 用 日本語ファームウェア（以下F/W）25Ja と 書込ツール 25Ja Tool の使い方

ご注意 ・元のデータが必要なときは、先にバックアップしておいてください。F/Wは、公式その他のツールで元に戻したり、上書きしたりできます。
・F/Wの書き換えは自己責任で行ってください。書き換えにより故障・保証外となる場合があります。
・無線局の設備として認証を受けていない無線機から電波を出すことは電波法違反です。送信は、適法に運用できる無線機・免許の範囲で行ってください。
送信について 25Ja を初めて入れた直後は、すべての周波数で送信できません（隠しメニューの「バンド ロック」が「全送信 禁止」になっています）。
SK1 と PTT を押したまま電源を入れ、隠しメニューの「バンド ロック」で使う範囲（例：JA/CE HAM 144〜146／430〜440MHz）を選ぶと送信できます（12 章「送信の制限（バンド ロック）」を参照）。

1. 25Ja とは

UV-K1 / UV-K5(K6) V3 用の、日本語で使える F/W です（Dondji v5.2.8 をもとにしています）。

ポイントは次の 4 つです。

  1. CH 名とメニューが、漢字・かなで表示されます CH 名は最大 31 バイト（漢字・かな 10 字）。ギリシャ文字・記号なども使えます。CH 名は PC の CPS「NeonPlugJA」で書きます。メニューは「表示言語」で日本語・英語の切替が可能です。メイン画面での長い名前は表示が切れることがあります。
  2. クイックスキャン 7 長押し（または F＋7）で、スキャン グループを選んですぐスキャンを始められます（7.2「スキャン中の操作」を参照）。
  3. FM 放送の局名が出ます 受信中の周波数に合う局名を、周波数の下に表示します（最大 127 局、漢字・かな 9 字まで）。局名は別ページの「25Ja FM局名ツール」で書きます（9.4「局名の入れ方」を参照）。
  4. 初めて入れた直後は、送信できません 隠しメニューの「バンド ロック」で使う範囲（例：JA/CE HAM ＝ 144〜146 / 430〜440MHz）を選ぶと送信できます（12 章「送信の制限（バンド ロック）」を参照）。

そのほかの変更

  • メニューを 5 つの分類（チャンネル／表示・音声／キー設定／システム／スキャン）に再編成しました。
  • 送信出力は、Low1〜Low5、Medium、High の 7 段階です。
  • 書体データの高速書込に対応しました。
  • 画面転送：PC やスマホから、25Dock で本体の画面をリモートで見て、キー操作もできます。
  • 新しい起動ロゴ（招き猫）を入れました。ロゴは、25Ja Tool の「6 起動画像」で、好きな 128×64 の白黒画像に変更できます（11 章「そのほかの機能（ツール）」を参照）。
  • 日本では使わない機能を外して、容量を空けました。

3. 準備

  1. PC（Windows / Mac / Linux）に Chrome または Edge を用意します（Web Serial を使うため。Safari・Firefox・スマートフォンは不可）。
  2. 無線機と PC を USB ケーブルでつなぎます。
  3. 配布の ZIP を展開し、25Ja_Tool フォルダの index.html をダブルクリックして開きます。
    Chrome / Edge 以外のブラウザで開いたときは、index.html を右クリック →「プログラムから開く」→ Chrome（または Edge）を選びます。
  4. 同梱のF/W・書体データをツールが自動で認識しない場合は、「F/Wの書込」「書体データの書込」の欄の「ファイルを選ぶ」で、 同じフォルダの firmware/25Ja_v0.5.1.bin（F/W）、font/25Ja_font_v5.bin（書体データ）を選んでください。
書き込むときの注意 ・違うファイルを選んでも、ツールが大きさ・中身の目印・版数を確かめて受け付けません（F/W欄に書体データを選んだときも止めます）。
・書込中はツールのタブを開いたままにしてください。別のタブや画面に切り替えても止まりはしませんが、遅くなることがあります。

4. 初めて 25Ja を入れる

ツール上部の「0 初めて 25Ja を入れる手順」の番号を押すとその欄へ移動するので、各欄のボタンで進めます。終わった欄には ✔（失敗は ✖）が付きます。

欄無線機の状態操作
校正データのバックアップ普通に起動「校正データを読み出す」→「calibration.dat を保存」。この無線機専用の大切なデータです。必ず保管してください。（複数台お持ちなら、S/N をファイル名につけておくと分かりやすいです。）
F/Wの書込電源を切り、PTT を押したまま電源 ON（F/W 書込モード）ファイルを選び（firmware/25Ja_v0.5.1.bin）→「書き込む」。終わると再起動します
リセット再起動後本体の隠しメニュー（SK1 と PTT を押したまま電源 ON。12 章「送信の制限（バンド ロック）」を参照）の リセット → 全部 を実行し、手順の「済んだ」に印を付けます。この時点では送信できません。送信するときは、同じ隠しメニューの「バンド ロック」で使う範囲を選びます（12 章「送信の制限（バンド ロック）」を参照）
書体データの書込普通に起動ファイルを選び（font/25Ja_font_v5.bin）→「書き込む」。最後に全体を照合します
校正データの復元（必要なときだけ）普通に起動通常は不要です。
校正データは、リセット・F/W書込・書体データの書込・NeonPlugJA の操作では書き換わりません。
校正データが変わるのは、隠しメニューの「電池校正」（12 バイト）と、この復元操作だけです。受信感度や送信出力がおかしいときだけ復元（書き戻す）を行ってください。書き戻すと、バックアップを取った後に行った電池校正は上書きされ、バックアップ時点の値に戻ります。電池校正を変えたときは、1 の校正データのバックアップを取り直しておくと戻りません。終わると再起動します

最後に本体メニュー「表示言語」を日本語にします。本体情報の「字数」が「6879」、「検査」が「正常」になっていれば、書体データは正しく入っています。

ツールの使いかた ・ボタンを押すたびに、ブラウザがシリアルポートの選択を求めます。無線機のポートを選んでください。
・校正データの復元が必要になったときは、保存した calibration.dat を「校正データの復元」の欄で選んで書き戻せます。
・途中で止まったら、その欄からやり直せます。

5. F/Wだけ更新する

書体データ・CH・設定は無線機の SPI フラッシュに残るので、F/Wの更新は「2 F/Wの書込」だけで済みます。

  1. 電源を切り、PTT を押したまま電源 ON（F/W 書込モード）。
  2. 「同梱のF/Wを使う」→「書き込む」。

書体データの版数が変わったときは、書体データも書き直してください。

6. キーの呼び方

6〜9 章は、F/W の操作（スキャン・スペクトラム・FM 放送）の説明です。SK1・SK2 は、本体の側面にある 2 つのキー（サイドキー）の呼び名です。

キー本書での呼び方・働き
SK1初期設定：短押しでモニター（メニュー「SK1短押」「SK1長押」で変更可）
SK2初期設定：短押しでスキャン（メニュー「SK2短押」「SK2長押」で変更可）
FF を押してから次のキーを押すと、そのキーの第 2 機能
長押し数字キーの長押しは、多くが「F＋数字」と同じ働きです（0・1・2・3・4・6・7。7 は、どちらもクイックスキャン）。違うのは次の 3 つです。
5：F＋5 はスペクトラム、長押しは範囲スキャン（7.4「範囲スキャン」を参照）。
8：F＋8 は照明の一時切替（最小／最大）、長押しは周波数の反転。
9：F＋9 は照明を設定どおりに戻す、長押しは呼出 CH。

7. スキャン

スキャンする CH のまとまりを「スキャン グループ」（以下グループ）と呼びます（10 章「スキャン グループ」を参照）。

7.1 使い分け

目的操作向いている場面
グループを選んでスキャンクイックスキャン：7 長押し（または F＋7）→ ＞・＜ で選ぶ → MENUスキャンするグループをその場で変えたい
グループスキャンの再開CH モードで ＊ 長押し（または F＋＊）前回のグループで、ポップアップなしにすぐ始めたい
空き周波数を探すVFO モードで ＊ 長押しバンドの様子見
範囲を決めて探す範囲スキャン：上段・下段に上限と下限を入れ、5 長押し → ＊ 長押し（7.4「範囲スキャン」を参照）430.00〜431.00 MHz など
クイックコピー4 長押し（または F＋4）近くの無線機の周波数とトーンを、すぐ自分の無線機にコピーしたい（同じ機種や似た機種とすぐ通信したいとき）
トーンだけ調べるVFO モードで F＋＊周波数は分かっていて、CTCSS／DCS が分からない
周りの電波を一覧で見るF＋5（スペクトラム）周辺周波数状況の確認

スキャン中は、CH や周波数が次々に切り替わります（画面にグループは出ません）。信号を受信すると止まり、「RX」の表示が出て、CH 名が反転表示になります。

7.2 スキャン中の操作

操作動き範囲

F＋上下、SK1／SK2F＋上・SK1 で次のグループ、F＋下・SK2 で前のグループ（CH モードのスキャン中は、SK1・SK2 に割り当てた機能は働きません）CH が入っているグループだけを順に

クイックスキャン（7 長押し、または F＋7）：グループを選んで、すぐスキャンを始めます。
  1. CH モードで 7 を長押し（または F＋7）。グループを選ぶ小さな画面が出ます（上の行＝一つ前、白黒反転の行＝選択中、下の行＝一つ後）。
  2. ＞ で上へ、＜ で下へ。24 の次は 01 に戻ります。CH が入っていないグループは出ません。

・選んでいる間は、SK1 が「＞」、SK2 が「＜」の代わりになります（SK1・SK2 に割り当てた機能は働きません）。ほかのキーは働きません。
・スキャン中でも使えます（決めると、新しいグループで最初からやり直します）。VFO モードのときは、CH モードに切り替わります。
・選んだグループは記憶されます（電源を入れ直しても残り、次は前回のグループから）。

7.4 範囲スキャン（5 長押し）

VFO の上段と下段に入れた 2 つの周波数の間だけをスキャンします。

  1. 2画面表示にして、VFO モードで、上段と下段に範囲の端の周波数を入れます（どちらが上でもかまいません）。
  2. 5 を長押しします。上段と下段の間が、スキャンの範囲になります。
  3. ＊ を長押しすると、その範囲だけをスキャンします。
  4. 止めるときは EXIT（スキャンが止まります）。範囲スキャンをやめるときは、もう一度 EXIT、または 5 を長押しします。
範囲スキャンの条件2画面表示（または 2 つの VFO を使う設定）のときだけ使えます。メインのみの表示では、エラー音が鳴ります。CH モードでは、5 長押しは何もしません。

9.3 放送局を登録する

  1. 周波数モードで聞きたい局に合わせる（数字入力、上下、または ＊）。
  2. MENU を押す → 登録先の番号（空いている番号）が出る。
  3. 番号を変えるときは上下か数字 2 桁（01〜48）。
  4. MENU で登録。やめるときは EXIT。

まとめて登録するなら ＊ 長押し（自動登録）。ただし、それまでの登録は消えます。

FM 放送の局名は、別ページの「25Ja FM局名ツール」（fm.html）で本体の局名表に書きます（メモリ CH やメニューでは設定しません。メニューに「FM 局名」の項目はありません）。

9.4 局名の入れ方（25Ja FM局名ツール）

25Ja FM局名ツール（fm.html）は、25Ja Tool（index.html）とは別のページです。同じ要領で、PC の Chrome / Edge で開き、無線機を普通に起動して USB でつなぎます。

  1. 本体を FM ラジオにして、右上のバンド表示が 76-108MHz になっていることを確かめます（バンド表示は 1 長押し、または F → 1 で変わります）。* 長押しで局をサーチして、プリセットに入れます（今のプリセット 48CH は全部消えます）。
  2. ツールで「エリア」を選び、「プリセットを取り込み、局名を入れる」を押します。本体のプリセットの周波数に、同じ周波数の局名が入ります（内蔵の局名データベースは、総務省「全国民放FM局・ワイドFM局一覧」令和7年4月1日現在。民放のみで、NHK とコミュニティ放送は入っていません）。
  3. 表で局名を確かめ、必要なら直して、「書き込む」を押します。FM ラジオに入り直すと局名が出ます。
  4. 不要なプリセットを消すときは、本体で F → 3（CH モード）→ 消したい CH を選ぶ → MENU →「CH○○を削除?」と出たら、もう一度 MENU（9.2 のとおり）。

表の周波数を「表の周波数を書く」でプリセット 48CH に書くこともできます（今のプリセットは置き換わり、書いた後に無線機が再起動します）。表の読み出し・消去、CSV の書出し・読込もツールにあります。

9.5 局名の決まり

  • 最大 127 局。周波数は 64.0〜108.0MHz、0.1MHz 単位、重複なし
  • 局名は UTF-8 で 28 バイト・画面幅 128 ドットまで（漢字・かな・ギリシャ文字などの全角の字は 9 字、半角英数は 18 字まで）
  • 使える字は半角英数記号と、全角の字（書体データの JIS X 0208 の全字。ギリシャ文字・キリル文字・記号を含む）。絵文字など 4 バイトの字は不可です。書体データにない字（半角カナなど）は、本体では全角幅の空白で出ます。ツールは、字数とバイト数・幅の超過を知らせます
  • CSV は「周波数,局名」の 2 列。読込は UTF-8 / Shift_JIS、書出は UTF-8（BOM 付き）
局名が出る条件 局名は、受信中の周波数と表の周波数がぴったり一致したときに出ます。局名が出るのは、プリセットで選んだ局か、周波数を直接入れた局です。

10. CH 名・CH表示・スキャン グループ（本体メニュー）

CH の編集CH の編集は PC の CPS「NeonPlugJA」で行います（CHIRP には対応していません）。NeonPlugJA（https://github.com/ja2izu/NeonPlugJA）の使いかたは、「NeonPlugJA 取扱説明書」を見てください。NeonPlugJA は、infamy 氏の NeonPlug（MIT License、https://github.com/infamy/NeonPlug）をもとにしたフォークです。

本体メニューの構成

メニューの最初の画面は、5 つの分類のアイコンです。メニューを開くと、前回使った分類から始まります（電源を入れ直すと「チャンネル」から）。

  • 「CH表示」は、周波数／CH番号／名前／名前+周波数の 4 つから選びます（英語表示では FREQ／CHANNEL NUMBER／NAME／NAME + FREQ）。2 つの VFO を並べる通常のメイン画面では、CH 名の見え方（下の項）は変わりません。

CH 名の長さ

  • CH 名は 最大 31 バイト（UTF-8）です。英数字は 1 バイト、漢字・かなは 3 バイト、ギリシャ文字・キリル文字と一部の記号（° ± × ÷ など）は 2 バイトで数えるので、英数字だけなら 31 字、漢字・かなだけなら 10 字、ギリシャ文字だけなら 15 字です。例：29MHz に全角 9 字を続けると 5 ＋ 27 ＝ 32 バイトで、1 バイト超えます。

メイン画面での CH 名の見え方

  • CH 名に漢字・かなを含むと、名前が大きい文字で出て、周波数は上の細い帯に移ります。
  • CH 名が英数字だけだと、周波数が大きく出て、名前は上の細い帯の左端に小さく出ます（Dondji 元来の画面の作りで、25Ja では変えていません）。
  • 日本語の名前を大きく見せたいときは、漢字・かなを 1 字以上入れてください。

スキャン グループ

  • グループは固定の 24 個（1〜24）です（作成や削除の操作はありません）。CH ごとに、どのグループに入れるかを選びます。0 はどのグループにも入らない（スキャンしない）、ALL はすべてのグループに入る、の意味です。
  • メニューの「所属 グループ」（チャンネルの中）は、その CH が入るグループ。「スキャン グループ」（スキャンの中）は、スキャンするグループの選択です。
  • グループ名は 12 バイト（漢字 4 字）までで、PC の CPS から書き込み・読み込みできます。メニューの値は「03 防災」のように、番号と名前で出ます（名前が空なら番号だけ、ALL は「ALL」）。
  • スキャン中にグループを切り替えると、番号と名前の小さな表示が一時的に出ます。
  • 本体の初期化（工場リセット）で、グループ名も消えます。
  • スキャン中に MENU 長押しで外した CH は、「除外」の印が付きます。電源を入れ直すと元に戻ります。

スキャン速度

  • F4HWN の高速スキャン（SCAN_FASTER）と RSSI 表示を移植しています。メニューの「スキャン 速度」で 通常／高速 を選びます。
  • それまでの 25Ja から更新したときの初期値は高速です。設定が消去されている・不正なときは通常です。
  • RSSI の表示は、メインのみの画面に出ます。

12. 送信の制限（バンド ロック）

25Ja を初めて入れた直後は、すべての周波数で送信できません（隠しメニューの「バンド ロック」が「全送信 禁止」）。送信しようとすると「TX DISABLE」と出ます。次のときも同じ状態になります：ほかの F/W から 25Ja を入れたとき、F/W 0.4.x から 0.5 以降に更新したとき、リセット（全部）のあと、25Ja Tool で F/W 0.4.x のときの設定バックアップを書き戻したとき。

送信するには、SK1 と PTT を押したまま電源 ON で隠しメニューを出し、「システム」の「バンド ロック」（F Lock）で使う範囲を選びます。日本のアマチュア無線では「JA/CE HAM」を選ぶと、送信できるのは 144〜146MHz と 430〜440MHz だけになります。このとき CH ごとの送信許可（TxLock）の設定は無視されます。「全送信 禁止」を選ぶと、再び送信できなくなります。

SK2 と PTT の組み合わせは、AIRCOPY が無効のためエラー画面になります。

隠しメニューに入っている項目：バンド ロック、電池校正、電池種類、機種依存 キー、リセット（いずれも「システム」の中）。
