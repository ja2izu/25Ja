# 25Ja Tool

UV-K1 / UV-K5(K6) V3 用 25Ja（にこじゃ）F/Wの書込ツール。PC の Chrome / Edge（Web Serial）で動く 1 ページのツール。

## 機能
0. 初めての手順（校正バックアップ → F/W → 初期化 → 字庫 → 校正復元。番号で各欄へ移動し、結果を ✔ / ✖ で表示）
1. 校正データのバックアップ（512 B）
2. F/Wの書込（刷机モード：PTT を押したまま電源 ON）
3. 字庫（東雲 12 ドット, 6647 字）の書込。25Ja 同士はセクタ単位の高速書込（0x0523）、古いF/Wは従来方式。最後に全体を照合
4. 校正データの復元
5. 設定領域の一括バックアップ・復元（SPI 0xA000–0xA21F, 544 B の生バイト。NeonPlugJA が扱わない領域も含む。旧 512 B 形式も復元可）
6. 起動画像（128×64、見出し `25Ja`）の書込・無効化
7. FM 局名（最大 127 局, SPI 0x012000）の編集・本体 FM プリセット（48CH）の周波数の取り込み・表の周波数を FM プリセットに書く（書込後再起動）・CSV 読込（UTF-8 / Shift_JIS）・書出・本体への書込・読出・消去。局名は 28 バイト・幅 128 ドットまで、字庫にない字は受け付けない

そのほか: ログのコピー（版・日時付き）・消去、「ファイルを選ぶ」ボタン（選んだ名前と検査結果を欄に表示）、接続時に本体の 25Ja 目印（挨拶応答 Version[13..15] = 0x25 'J' 機能ビット, bit0 = CH 名 31 B）をログに表示。

誤操作防止: F/W欄は先頭のベクタ表（スタック値・開始番地）とサイズ、字庫欄はサイズ・先頭の値・版数を確かめ、合わないファイルは受け付けない。刷机モード/通常起動の取り違えも検出して止める。

## 使い方
- 利用者: ZIP を展開し `index.html` をダブルクリック（Chrome / Edge）。同梱のF/W・字庫はボタンを押すとファイル選択が出るので、`firmware/` `font/` のファイルを選ぶ。
- 開発者: `cd web && python3 -m http.server 8000` → `http://localhost:8000` で開くと同梱ファイルを自動で読む（https で公開した場合も同じ）。
- 実機の Chrome（Windows）で、直開き（file://）でも Web Serial の接続・読み書き（FM 局名表）ができることを確認済み（2026-09-28）。

## ファイル
- index.html — ツール本体（外部ライブラリなし, Ver 0.1.13）
- manual.html — 説明書（初回の書込・更新・FM 局名・困ったとき・配布前の確認表）
- firmware/25Ja_v0.4.1.bin — 同梱F/W
- font/25Ja_font_v4.bin — 同梱字庫
- test/sim.js — 模擬無線機を使った動作試験（Node.js + jsdom）。`CASES='^7' node sim.js` で一部だけ実行（全 30 件）
