25Ja FM局名ツール

UV-K1 / UV-K5(K6) V3 用 25Ja F/W の FM 局名表（SPI 0x012000）と FM プリセット 48CH（0x00A028）の編集。Chrome / Edge（Web Serial）で使います。無線機は普通に起動した状態で接続します。

埋め込み表示のため、シリアルポートを使えません。このファイルを保存して、PC の Chrome / Edge で直接開いてください（ファイルをダブルクリック、またはブラウザにドラッグ）。チャットやプレビューの中では接続できません。
このブラウザは Web Serial に対応していません。PC の Chrome か Edge で開いてください。
最初にお読みください：無線機の SPI フラッシュを書き換えます。書き込むのは局名表（0x012000 から）と、「表の周波数を書く」を押したときの FM プリセット（0x00A028 から 96 バイト）だけです。

簡単な使い方

  1. 本体を FM ラジオにして、右上のバンド表示が 76-108MHz になっていることを確認します（バンド表示は「1」を長押しすると変わります）。★ を長押しして局をサーチします（今のプリセット 48CH は全部消えます）。
  2. 下の「局名データベース」でエリアを選び、「プリセットを取り込み、局名を入れる」を押します。
  3. その下の「FM 局名」の表で局名を確認・修正して、「書き込む」を押します。
不要なプリセットを消すとき：本体で F＋3 を押して CH モードにし、消したい CH を選んで MENU を押します。「CH○○を削除?」と出たら、もう一度 MENU で確定します。

局名データベース 通常起動 総務省「全国民放FM局・ワイドFM局一覧」（令和7年4月1日現在）を元にした内蔵データ。民放のみ（NHK・コミュニティ放送は含みません）

列：エリア, 区分（ワイドFM / FM）, 局名, 中継局名, 周波数MHz, 備考。書出しは UTF-8（BOM 付き, Excel で開けます）、読込は UTF-8 / Shift_JIS。局名が 28 バイトまたは幅 128 ドットを超える行は、書き出すときに備考へ文字数が入ります。局名データベースは保存しません。使うたびに内蔵のもの、または読み込んだ CSV になります。
