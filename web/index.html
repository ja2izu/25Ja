25Ja Tool

UV-K1 / UV-K5(K6) V3 用 25Ja（にこじゃ）ファームの書込・字庫・校正バックアップ。Chrome / Edge（Web Serial）で使います。説明書

ファイルを直接開いています。この開き方では同梱のファーム・字庫を自動で読めないため、2・3 の欄の「ファイルを選ぶ」で firmware/25Ja_v0.4.bin・font/25Ja_font_v4.bin を選んでください。
このブラウザは Web Serial に対応していません。PC の Chrome か Edge で開いてください。

0初めて 25Ja を入れる手順 番号を押すとその欄へ移動します。ファームだけ更新するときは 2 だけで済みます（字庫は残ります）

  1. 1 校正バックアップ普通に起動
  2. 2 ファームPTT を押したまま電源 ON
  3. 本体で リセット → 全部隠しメニューで実行
  4. 3 字庫普通に起動
  5. 4 校正復元終わると再起動

書込は自己責任です。技適のない無線機から電波を出すのは電波法違反です。

1校正データのバックアップ 通常起動

書込前のファームのうちに一度取り、大切に保管してください（512 バイト）。読み出すと 4 の欄にも入ります。

calibration.dat を保存

2ファームの書込 刷机モード

電源を切り、PTT を押したまま電源を入れて（刷机モード＝ファームを書き込むための状態）から「書き込む」を押します。

未選択（「ファイルを選ぶ」か「同梱のファームを使う」）

3字庫（東雲フォント）の書込 通常起動

ファームを書いた後に書きます。最後に全体を読み戻して照合します。ファームと字庫は同じ版の組で使ってください。

未選択（「ファイルを選ぶ」か「同梱の字庫を使う」）

4校正データの復元 通常起動

保存した calibration.dat を書き戻します（1 で読み出した直後なら選び直し不要）。終わると再起動します。

未選択

5設定のバックアップ・復元 通常起動

本体の設定（SPI 0xA000〜0xA21F, 544 バイト）。CH とその名前は含みません。

25Ja_config.bin を保存
未選択

6起動画像 通常起動

128×64 の白黒画像。本体メニュー「起動画面」を「ロゴ」にすると表示。明るい画素が点灯します。

7FM 局名 通常起動 最大 127 局。局名は 28 バイト・幅 128 ドットまで（漢字・かな 9 字、半角英数 18 字）。書いた後、FM ラジオに入り直すと反映

※ この機能はまだ不完全です。内容を確認しながら使ってください。
