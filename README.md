# 25Ja（にこじゃ）

Quansheng UV-K1 / UV-K5(K6) V3 用ファームウェア（以下F/W）。漢字・かな表示に対応した派生版です。

**このプロジェクトは Dondji v5.2.8（BD1AHN、Apache License 2.0）をベースにしています。** Dondji 公式のものではなく、BD1AHN とは無関係です。Dondji はさらに F4HWN などをベースにしています（NOTICE 参照）。

## 主な機能
- チャンネル名・メニューの漢字／かな表示（SPI フラッシュの字庫、東雲 12 ドット 6,647 字）
- チャンネル名 31 バイト（漢字 10 字）まで登録可能
  - メイン画面で表示できる漢字は 7 文字まで。8 文字目以降は欠け、右側の表示と重なることがあります
- FM 局名の表示（最大 127 局）
- スキャングループ切替時にグループ名をすぐ更新
- スキャングループの漢字名（漢字 4 文字／12 バイトまで）。メニューの値と、スキャン中にグループを切り替えたときのポップアップに「03 防災」の形で出ます。名前が無い枠は番号だけです。名前の書込・読込は NeonPlugJA（0.91.7 以降）で行います
- 高速スキャンと、スキャン中の RSSI 表示（F4HWN から移植）。メニュー「スキャン 速度」で通常／高速を切り替えます
- F/Wの版数を書込ツール・CPS に返します（0.4 以降。挨拶応答に入れる）
- メニューを 5 分類（チャンネル／表示/音声／キー設定／システム／スキャン）に再編成。送信出力から USER を廃止（Low1〜Low5・Medium・High）
- 起動表示（値 1）に、NeonPlugJA から好きな文言を書けます（24 バイトまで・表示幅 128 ドット以内）
- F→8 / F→9 でバックライト操作
- レンジスキャン中の周波数除外（MENU 長押し。F4HWN 6.0.0 から移植。最大 64 件、電源断で消える）
- 書込ツール **25Ja Tool**（`web/`、Chrome / Edge の Web Serial で動作）

## 使い方
`web/manual.html` を参照してください。`web/index.html` をブラウザで開き、手順に従ってF/W・字庫を書き込みます。校正データのバックアップを先に取ってください。

## ビルド
xPack arm-none-eabi-gcc 13 系で確認しています。

```
cmake --preset Fusion && cmake --build --preset Fusion -j8
```

F/Wの上限は 120,832 バイトです。
