# 25Ja（にこじゃ）

Quansheng UV-K1 / UV-K5(K6) V3 用ファームウェア（以下F/W）。漢字・かな表示に対応した派生版です。

**このプロジェクトは Dondji v5.2.8（BD1AHN、Apache License 2.0）をベースにしています。** Dondji 公式のものではなく、BD1AHN とは無関係です。Dondji はさらに F4HWN などをベースにしています（NOTICE 参照）。

## 主な機能
- CH 名・メニューの漢字／かな表示（SPI フラッシュの書体データ、東雲 12 ドット JIS X 0208 の全 6,879 字。ギリシャ文字・キリル文字・記号を含む）
- CH 名 31 バイト（漢字 10 字）まで登録可能
  - メイン画面で表示できる漢字は 7 文字まで。8 文字目以降は欠け、右側の表示と重なることがあります
- FM 局名の表示（最大 127 局）
- スキャン グループ切替時にグループ名をすぐ更新
- スキャン グループの漢字名（漢字 4 文字／12 バイトまで）。メニューの値と、スキャン中にグループを切り替えたときのポップアップに「03 防災」の形で出ます。名前が無い枠は番号だけです。名前の書込・読込は NeonPlugJA（0.91.7 以降）で行います
- 高速スキャンと、スキャン中の RSSI 表示（F4HWN から移植）。メニュー「スキャン 速度」で通常／高速を切り替えます
- F/Wの版数を書込ツール・CPS に返します（0.4 以降。挨拶応答に入れる）
- メニューを 5 分類（チャンネル／表示/音声／キー設定／システム／スキャン）に再編成。送信出力から USER を廃止（Low1〜Low5・Medium・High）
- 起動表示（値 1）に、NeonPlugJA から好きな文言を書けます（24 バイトまで・表示幅 128 ドット以内）
- F＋8 / F＋9 でバックライト操作
- レンジスキャン中の周波数除外（MENU 長押し。F4HWN 6.0.0 から移植。最大 64 件、電源断で消える）
- クイックスキャン：7 長押し（F＋7）でスキャン グループを選んで、すぐスキャンを開始
- メニューを開くと前回の分類から始まる
- 初めて入れた直後は送信を全周波数で禁止（隠しメニュー「バンド ロック」で解除）
- 書込ツール **25Ja Tool**（`web/`、Chrome / Edge の Web Serial で動作）

## 関連：PC の CPS「NeonPlugJA」
本体の設定・CH の書込は PC のブラウザ CPS「NeonPlugJA」（https://github.com/ja2izu/NeonPlugJA）で行えます（この配布物には含まれません）。CHIRP には対応していません。NeonPlugJA は、infamy 氏の NeonPlug（MIT License、https://github.com/infamy/NeonPlug）をもとにしたフォークです。

## 使い方
`web/manual.html` を参照してください。`web/index.html` をブラウザで開き、手順に従ってF/W・書体データを書き込みます。校正データのバックアップを先に取ってください。

**25Ja を初めて入れた直後は、すべての周波数で送信できません。** PF1 と PTT を押しながら電源を入れ、隠しメニューの「バンド ロック」で使う範囲（例：JA/CEアマ）を選ぶと送信できます。

## ビルド
xPack arm-none-eabi-gcc 13 系で確認しています。

```
cmake --preset Fusion && cmake --build --preset Fusion -j8
```

F/Wの上限は 120,832 バイトです。

## 版数
25Ja F/Wの版数は **0.5.1** です。F/W 0.5 以降は書体データ v5 と組で使います（0.4.x からの更新では、書体データの書込も必要です）。本体の情報画面の「ビルド日時」は版数とは別です（ビルドした日付。コミット名は実機では表示されません）。
